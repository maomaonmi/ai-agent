# 千问深度调研链路接入计划

## 摘要

为千问模型接入 `qwen-deep-research` 专用深度研究模型，使用 DashScope HTTP API（非 OpenAI 兼容协议），支持两步式调用（反问确认 + 深入研究）和四阶段流式响应，前端适配 ResearchProgressPanel 展示。

## 一、当前架构

### 后端
- **端点**: `main.py` L5144 `@app.post("/deep_research")` → 调用 `generate_deep_research_events()`
- **引擎路由**: `research_engine` 字段为 `Literal["agent-loop", "firecrawl", "self-built"]`，默认 `agent-loop`
- **生成器**: `generate_deep_research_events()` (L5577) 根据引擎选择不同链路，推送 SSE 事件
- **事件格式**: `research_process`（stage/status/message）、`done`（top_chunks）、`research_reason_done`（report/reasoning）
- **千问 API Key**: 无独立 `QWEN_API_KEY` 全局变量，需从 `service_settings` 或 `ModelSettings.api_key` 获取

### 前端
- **api.ts**: `sendDeepResearch()` (L973) 发 POST 到 `/deep_research`，`ResearchEngine = 'firecrawl' | 'self-built'`
- **ChatInterface.tsx**: L2032-2070 深度调研模式 UI，千问模型目前只显示"千问使用原生研究模型"占位文本
- **ResearchProgressPanel.tsx**: 五阶段流水线（fanout→fetch→chunk→rerank→reason），硬编码了自研链路的阶段

### 千问深度调研 API
- **端点**: `https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation`
- **流式头**: `X-DashScope-SSE: enable`
- **模型**: `qwen-deep-research`
- **两步流程**: 反问确认（`enable_feedback=true`）→ 深入研究；`enable_feedback=false` 跳过第一步
- **四阶段 SSE**: `searching` → `processing` → `generating` → `finished`
- **Chunk 格式**: `{"output":{"choices":[{"message":{"content":"...","role":"assistant"}}]},"usage":{...}}`

**(a) 新增 `get_qwen_api_key()` 辅助函数**

从 `service_settings_store` 或环境变量获取千问 API Key（复用已有模式）。

**(b) 新增 `generate_qwen_deep_research_events()` 异步生成器**

签名：
```python
async def generate_qwen_deep_research_events(
    query: str,
    session_id: str | None,
    enable_feedback: bool,
    api_key: str,
) -> AsyncGenerator[str, None]:
```

核心流程：
1. **Phase 1 — 反问确认**（仅 `enable_feedback=True`）：
   - POST DashScope，`stream=True`，`parameters={"enable_feedback": True}`
   - 解析 SSE 行（`data: {...}`），提取 `output.choices[0].message.content`
   - 推送 `research_process` 事件：`stage="planning"`, `status="running"` → `"done"`
   - 推送 `qwen_feedback` 自定义事件携带反问内容，等待前端用户回答
   - 前端回答后继续 Phase 2

2. **Phase 2 — 深入研究**：
   - 构建多轮 messages（原始问题 + 反问 + 用户回答）
   - POST DashScope，`parameters={"enable_feedback": False}`
   - 解析四阶段 SSE 响应，映射到前端事件：
     - `searching` → `research_process(stage="searching", status="running")`
     - `processing` → `research_process(stage="analyzing", status="running")`
     - `generating` → `research_process(stage="writing", status="running")` + `token` 事件
     - `finished` → `research_process(stage="complete", status="done")`
   - 最终推送 `done` + `research_reason_done` 事件

3. **SSE 解析辅助函数** `_parse_dashscope_sse_line(raw: str) -> dict | None`：
   - 处理 `data: {...}` 格式
   - 提取 `output.choices[0].message.content`
   - 检测阶段转换（通过 content 中的特殊标记或 usage 字段）

**(c) 修改 `/deep_research` 端点**

在 `generate_deep_research_events()` 开头新增分支：
```python
if research_engine == "qwen":
    api_key = get_qwen_api_key()

        yield sse_format("error", {"message": "未配置千问 API Key"})

    enable_feedback = (research_options or {}).get("enable_feedback", False)
    async for item in generate_qwen_deep_research_events(query, session_id, enable_feedback, api_key):

    return
```

## 三、SSE 事件映射

| 千问 API 阶段 | 前端 stage | 前端 status | 额外数据 |
|---|---|---|---|
| 反问输出 | `planning` | `running` → `done` | `message`: 反问内容 |
| searching | `searching` | `running` → `done` | — |
| processing | `analyzing` | `running` → `done` | — |
| generating | `writing` | `running` | `token` 事件流式输出 |
| finished | `complete` | `done` | — |

反问交互使用自定义事件 `qwen_feedback`，不在标准阶段内。
