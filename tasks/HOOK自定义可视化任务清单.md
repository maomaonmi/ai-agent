# HOOK 自定义可视化任务清单

## 已确认约束

- 本地单用户。
- 第一版只实现内置 HOOK。
- 运行历史默认保留摘要和最近 100 次 run。
- 实时观察面板默认折叠。

## 阶段 0：契约和后端基础

- [x] 任务 1：定义 HOOK 配置、生命周期、状态和统一事件信封
  - 验收：Python 类型、JSON 示例和字段级脱敏规则明确；事件可表达通过、修改、阻断、异常四种结果。
  - 验证：新增单元测试覆盖序列化、去重键和敏感字段过滤。
  - 依赖：无。
  - 文件：`HOOK/` 新增契约模块、`tests/` 新增契约测试、计划书。

- [x] 任务 2：增强 HookRegistry 的顺序、启停和执行观测
  - 验收：支持 priority、enabled、handler 元数据；Hook 异常不会静默吞掉；每次执行产生统一摘要。
  - 验证：覆盖多个 Hook 顺序、阻断短路、异常 fail-open 和变更 diff。
  - 依赖：任务 1。
  - 文件：`HOOK/agent_hook_engine.py`、`HOOK/` 契约模块、`tests/`。

- [x] 任务 3：接入代码 Agent 的生命周期锚点
  - 验收：LLM 调用前后、工具调用前后、错误路径能产生 HOOK 事件；不改变现有工具循环结果。
  - 验证：针对 `App.py` 的工具循环增加集成测试，确认阻断和放行两条路径。
  - 依赖：任务 2。
  - 文件：`App.py`、`HOOK/`、`tests/`。

### 检查点 A

- [ ] HOOK 原型和代码 Agent 事件链测试通过。
- [ ] 无原始 prompt、密钥或完整工具参数进入默认事件摘要。
- [ ] 与现有未提交改动无冲突。

## 阶段 1：HOOK 管理中心

- [ ] 任务 4：增加 HOOK 管理 API 和前端 API 类型
  - 验收：支持 list、detail、create/update、toggle、reorder、test；错误返回稳定。
  - 验证：FastAPI API 测试 + 前端 TypeScript 类型检查。
  - 依赖：任务 2。
  - 文件：`main.py` 或独立路由、`frontend/ai-agent/src/lib/api.ts`、`tests/`。

- [ ] 任务 5：增加侧边栏入口和 HOOK 工作区骨架
  - 验收：侧边栏一级入口可进入独立工作区；返回聊天后原状态不丢失；设置页保留策略入口。
  - 验证：浏览器手动检查导航、空状态、加载和错误状态。
  - 依赖：任务 4。
  - 文件：`ChatInterface.tsx`、新增 `HookCenter.tsx`、必要的布局文件。

- [ ] 任务 6：完成 HOOK 列表、详情、启停和声明式测试面板
  - 验收：可按生命周期/状态筛选；可启停和排序；测试面板展示输入摘要、结果和字段 diff。
  - 验证：组件测试或浏览器手动测试至少两种 HOOK。
  - 依赖：任务 5。
  - 文件：新增 HOOK 管理组件、`api.ts`、样式文件。

### 检查点 B

- [ ] 用户可在不运行真实 Agent 的情况下配置并测试 HOOK。
- [ ] 任意输入不会触发任意代码执行。
- [ ] 前端 lint/build 的新增错误为零。

## 阶段 2：实时观察中心

- [ ] 任务 7：统一聊天和代码 Agent 的 HOOK SSE 适配
  - 验收：两套后端流协议都能转换为同一前端事件模型；事件带 session/run/sequence。
  - 验证：模拟聊天和代码 Agent 流，确认前端收到同形事件。
  - 依赖：任务 3、任务 4。
  - 文件：`main.py`、`App.py`、`api.ts`、后端测试。

- [ ] 任务 8：实现前端 Hook 事件状态层和实时观察面板
  - 验收：面板默认折叠；出现事件显示徽标；展开后按时间线展示开始、完成、修改、阻断、异常。
  - 验证：浏览器中运行一次代码 Agent 和一次普通聊天，检查实时更新、折叠和错误态。
  - 依赖：任务 7。
  - 文件：新增 `HookMonitorPanel.tsx`、状态 Hook/类型文件、`ChatInterface.tsx`、`CodeWorkspace.tsx`。

- [ ] 任务 9：实现运行历史和时间线回放
  - 验收：可按 run、session、生命周期、结果筛选；刷新后可回放摘要；长事件流可折叠。
  - 验证：构造多 run 数据，检查排序、去重、分页/裁剪和空状态。
  - 依赖：任务 7、任务 8。
  - 文件：历史 API、HOOK 工作区组件、前端 API 类型、测试。

### 检查点 C

- [ ] 聊天和 CodeWorkspace 都能实时显示 HOOK。
- [ ] 断开/重连、重复事件和异常事件不导致 UI 崩溃。
- [ ] 运行历史与实时面板显示同一事件语义。

  - 验收：记录事件契约、添加内置 HOOK、排障方式、保留策略和边界。
  - 验证：按文档从空配置完成一次创建、测试、运行和回放。

- [ ] 所有新增后端测试通过。
