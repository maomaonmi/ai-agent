# AI 写作工作台 V1 任务清单

> 前置条件已满足：`tasks/ai-writing-plan.md` 第 17 节产品决策已于 2026-08-12 确认。

## Phase A：配置与契约

### Task 1：建立写作领域类型

**验收标准：**

- [ ] 定义场景、字段、选项、草稿、提示词结果和路由提示类型。
- [ ] 类型不引用具体 UI 组件或具体模型 SDK。

**验证：** `cd frontend/ai-agent && npx tsc --noEmit`

**依赖：** 无  
**预计文件：** `writingTypes.ts` 及测试文件  
**规模：** S

### Task 2：实现八个场景配置

**验收标准：**

- [ ] 八个场景、字段、全部选项和默认值与计划一致。
- [ ] 配置校验能发现重复 ID、缺失默认值和非法选项。

**验证：** 配置单元测试 + TypeScript 检查

**依赖：** Task 1  
**预计文件：** `writingScenes.ts`、配置测试  
**规模：** S

### Task 3：建立提示词编译器骨架

**验收标准：**

- [ ] 八个场景均在注册表中有编译器。
- [ ] React 组件中不存在场景 system prompt 字符串。
- [ ] V1 编译结果包含统一 system/user/constraints/routingHints 字段。

**验证：** 编译器注册与输出结构单元测试

**依赖：** Task 1、2  
**预计文件：** `prompts/` 下 3–5 个基础文件，后续场景文件分任务补齐  
**规模：** M

### Task 4：建立模型路由接口

**验收标准：**

- [ ] V1 所有任务安全回退到当前通用模型。
- [ ] 小说、论文、长上下文和意图识别能输出正确能力提示。
- [ ] 用户显式值不会被建议覆盖。

**验证：** 路由规则单元测试

**依赖：** Task 1、2  
**预计文件：** `writingModelRouter.ts`、测试文件  
**规模：** S

### Checkpoint A

- [ ] 配置、提示词契约、模型路由测试通过。
- [ ] 不接 UI 时现有应用仍能通过 TypeScript 检查。

## Phase B：工作台 UI

### Task 5：创建独立 AI 写作视图与入口

**验收标准：**

- [ ] “更多 → AI 写作”打开独立写作视图。
- [ ] 可返回原界面，未提交时不创建历史会话。
- [ ] 默认场景为通用。

**验证：** 浏览器手动检查入口、返回和历史侧栏

**依赖：** Task 1、2  
**预计文件：** `ChatInterface.tsx`、`WritingWorkspace.tsx`  
**规模：** S

### Task 6：实现主输入卡片

**验收标准：**

- [ ] 视觉层级与参考图一致，输入框自动增高。
- [ ] 附件、标签、参数区和提交按钮位置稳定。
- [ ] 长文本达到上限后内部滚动。

**验证：** 320/768/1024/1440px 浏览器检查

**依赖：** Task 5  
**预计文件：** `WritingComposer.tsx`、样式或测试文件  
**规模：** S

### Task 7：实现场景导航

**验收标准：**

- [ ] 八个场景卡片完整显示，选中态清晰。
- [ ] 切换场景不清空输入，各场景选择可恢复。
- [ ] 窄屏可横向滚动并自动展示选中项。

**验证：** 键盘、鼠标和移动端手动检查

**依赖：** Task 2、5  
**预计文件：** `WritingSceneTabs.tsx`、`WritingWorkspace.tsx`  
**规模：** S

### Task 8：实现动态参数栏与下拉控件

**验收标准：**

- [ ] 参数完全由当前场景配置生成。
- [ ] 下拉菜单支持方向键、Enter、Esc、点击外部关闭。
- [ ] 默认值和选中状态正确。

**验证：** 组件行为测试 + 浏览器键盘检查

**依赖：** Task 2、6、7  
**预计文件：** `WritingParameterBar.tsx`、`WritingSelect.tsx`、测试文件  
**规模：** M

### Task 9：实现移动端参数抽屉

**验收标准：**

- [ ] 小屏仅显示配置摘要和设置入口。
- [ ] 抽屉可应用或取消修改，并管理焦点。
- [ ] 页面无横向溢出。

**验证：** 320px 与 768px 浏览器检查

**依赖：** Task 8  
**预计文件：** 参数抽屉组件、参数栏  
**规模：** S

### Checkpoint B

- [ ] 八个场景和全部参数可完整操作。
- [ ] 产品完成一次视觉与交互审查。

## Phase C：请求与输出闭环

### Task 10：实现写作输入校验

**验收标准：**

- [ ] 空输入不能提交。
- [ ] 仿写、润色、扩写、缩写、续写缺少原文时给出明确提示。
- [ ] 字数和场景参数能规范化为请求数据。

**验证：** 校验单元测试

**依赖：** Task 1、2  
**预计文件：** `writingValidation.ts`、测试文件  
**规模：** S

### Task 11：接入现有生成链路

**验收标准：**

- [ ] 提交时编译结构化 writing context。
- [ ] 第一次提交后才创建写作会话。
- [ ] 支持流式输出、停止和错误恢复。

**验证：** 通用场景端到端手动测试 + API 契约测试

**依赖：** Task 3、4、5、10  
**预计文件：** API 类型、`ChatInterface.tsx`、写作工作台  
**规模：** M

### Task 12：实现写作结果区

**验收标准：**

- [ ] 包含初始、生成中、完成、停止、失败状态。
- [ ] 完成后显示实际字数。
- [ ] 失败或重试不清空输入与配置。

**验证：** 状态组件测试 + 手动中断请求

**依赖：** Task 11  
**预计文件：** `WritingResult.tsx`、工作台、测试文件  
**规模：** M

### Task 13：实现本地草稿恢复

**验收标准：**

- [ ] 刷新后恢复输入、场景和各场景最后参数。
- [ ] 用户可清除本地草稿。
- [ ] 损坏的本地数据不会导致页面崩溃。

**验证：** 存储单元测试 + 浏览器刷新检查

**依赖：** Task 5、7、8  
**预计文件：** 草稿 hook、工作台、测试文件  
**规模：** S

### Checkpoint C

- [ ] 通用、作文、小说、论文代表流程端到端可用。
- [ ] 未提交草稿不会出现在历史会话中。

## Phase D：质量验收

### Task 14：无障碍与响应式验收

**验收标准：**

- [ ] 完整键盘路径可用，焦点始终可见。
- [ ] 屏幕阅读器能识别场景、字段和选中状态。
- [ ] 减少动效设置生效。

**验证：** Tab 路径、浏览器辅助功能树、四档尺寸截图

**依赖：** Phase B、C  
**预计文件：** 仅必要的写作组件修正  
**规模：** S

### Task 15：最终回归与文档更新

**验收标准：**

- [ ] TypeScript、限定 lint、相关测试通过。
- [ ] 生产构建若被存量错误阻塞，提供与本功能无关的错误清单。
- [ ] 计划书和任务清单更新为实际完成状态，记录 V2 项目。

**验证：**

```powershell

npx tsc --noEmit
npx eslint src/features/ai-writing src/components/ChatInterface.tsx

```

**依赖：** 全部前置任务  
**预计文件：** 测试、计划文档、必要修正文件  
**规模：** S

### Final Checkpoint

- [ ] 产品确认场景、参数、视觉和首条生成链路。
- [ ] V1 范围全部满足，V2 能在不重构页面的前提下继续开发。
