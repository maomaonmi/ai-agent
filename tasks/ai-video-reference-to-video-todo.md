# AI 视频：参考视频生成（R2V）实施清单

> 当前状态：已完成首期 Wan R2V 业务闭环（OSS 直传、FFprobe/FFmpeg 预处理、异步任务、工作台第三入口）；Vidu2 多参考图与生产级并发/租约护栏仍待后续阶段。

## Phase 1：资产基础设施

### Task 1：定义参考资产契约与数据库迁移

**验收标准**

- [x] 定义 `video_reference_assets` 与参考素材快照契约。
- [x] 资产状态机覆盖上传、探测、转码、READY、拒绝和过期字段。
- [x] 数据库迁移可重复执行，不破坏现有视频任务表。

**验证**

- [ ] 迁移测试与状态转换测试通过。

**依赖**：无

### Task 2：实现 `ReferenceAssetStore` 与 OSS 适配器

**验收标准**

- [x] 私有 OSS Bucket，可签发 PUT 与 GET URL。
- [x] 签名 URL、AccessKey 不写日志、不进入任务快照。
- [ ] 原始与标准化对象的 OSS 24 小时生命周期规则（需在 OSS 控制台确认）。

**验证**

- [ ] 使用假存储完成契约测试。
- [ ] OSS 开发桶手动完成上传/读取/过期验证。

**依赖**：Task 1

### Task 3：实现上传 API

**验收标准**

- [x] 创建资产、完成上传、查询、删除四个接口完成。
- [x] `complete` 幂等并校验对象大小/类型。
- [x] 无 OSS 配置时明确返回配置错误，不返回 localhost URL。

**验证**

- [ ] FastAPI API 测试覆盖成功、超限、重复完成和删除。

**依赖**：Task 2

## Checkpoint A：上传链路

- [ ] 浏览器能直传 100 MB 以内测试文件。
- [ ] FastAPI 内存不会随上传文件大小线性增长。
- [ ] 私有对象无法匿名访问。

## Phase 2：预处理切面

### Task 4：实现 FFprobe 元数据探测

**验收标准**

- [x] 读取时长、宽高和视频编码；损坏/无视频流进入结构化 REJECTED 状态。
- [x] Wan 2.7 的时长、尺寸、画幅和体积规则完成后端校验。
- [ ] 补充帧率、音频编码和旋转信息字段。

**验证**

- [ ] 使用 MP4、MOV、HEVC、损坏文件夹具测试。

**依赖**：Task 3

### Task 5：实现 FFmpeg 标准化工作者

**验收标准**

- [x] 输出 MP4/H.264/yuv420p/AAC。
- [x] 配置 FFmpeg 超时；临时文件在处理后清理。
- [x] 已合规 MP4/H.264 文件跳过转码；不静默截断超长视频。
- [ ] 多实例数据库租约、并发上限和临时目录配额。

**验证**

- [ ] 转码输出再次通过 FFprobe 契约测试。
- [ ] 工作者重启后任务可恢复且不重复转码。

**依赖**：Task 4

## Checkpoint B：资产 READY

- [ ] 上传后状态能完整流转到 READY/REJECTED。
- [ ] 预处理进度可查询。
- [ ] 重启应用后未完成任务可以恢复。

## Phase 3：Wan 2.7 最小闭环

### Task 6：扩展模型矩阵与请求模型

**验收标准**

- [x] 新增 `reference_to_video` 模式和四个千问模型。
- [x] 引用只接受 READY `assetId`，数量和类型按能力矩阵校验。
- [x] 现有文生/图生请求保持向后兼容。

**验证**

- [ ] Pydantic 边界测试和工作台契约测试通过。

**依赖**：Task 5

### Task 7：实现 Wan 2.7 Payload 转换器

**验收标准**

- [x] `media[]` 类型、顺序和临时签名 URL 正确。
- [x] 主线与快照模型均支持。
- [x] 提交前重新生成 6 小时签名 GET URL。

**验证**

- [ ] 官方示例形成黄金 Payload 测试。
- [ ] 真实 API 冒烟测试仅手动执行一次。

**依赖**：Task 6

### Task 8：接入异步监控与输出转存

**验收标准**

- [ ] Task ID 持久化、5 秒轮询、SSE 和刷新恢复正常。
- [ ] 成功后立即转存 24 小时输出 URL。
- [ ] 网络不确定提交进入 `SUBMISSION_UNKNOWN`，不盲重试。

**验证**

- [ ] 断网、重启、SSE 断连和供应商失败测试通过。

**依赖**：Task 7

## Checkpoint C：Wan 2.7 单视频闭环

- [ ] 一段本地视频可上传、预处理、提交、恢复和下载。
- [ ] 重复点击不会产生第二个付费任务。
- [ ] 历史记录可恢复任务与参考资产信息。

## Phase 4：Wan 2.6 与多素材

### Task 9：实现 Wan 2.6 转换器

**验收标准**

- [x] `reference_urls[]` 顺序正确。
- [x] `size`、`shot_type`、`audio` 参数按模型校验。
- [x] 非 Flash 模型拒绝静音模式。

**验证**

- [ ] 两个模型各有黄金 Payload 测试。

**依赖**：Task 8

### Task 10：实现多参考素材与用途语义

**验收标准**

- [ ] 最多 3 个视频、总共 5 个素材。
- [ ] 支持主体/动作/风格/场景用途并生成提示词模板。
- [ ] UI 明确用途不是供应商权重保证。

**验证**

- [ ] 混合图片/视频顺序和别名测试通过。

**依赖**：Task 9

## Phase 5：工作台与成本护栏

### Task 11：实现参考视频上传工作台

**验收标准**

- [x] 上传卡显示缩略图、上传/预处理进度和媒体元数据。
- [x] 未 READY、超数量或参数无效时禁止提交。
- [x] 沿用现有主题色，不添加积分按钮。

**验证**

- [ ] TypeScript、ESLint、响应式和明暗主题浏览器测试通过。

**依赖**：Task 10

### Task 12：实现幂等、并发和熔断

**验收标准**

- [ ] 每会话默认只允许 1 个在途 R2V 任务。
- [ ] 4xx 不重试；429/5xx 仅在确认未创建远端任务时退避重试。
- [ ] 记录计费相关时长、重试次数和 request ID。

**验证**

- [ ] 并发提交、双击、超时和限流测试通过。

**依赖**：Task 11

## Phase 6：Vidu 2 多参考图（独立能力）

### Task 13：接入 `vidu2-reference`

**验收标准**

- [ ] 只接受图片资产并调用 `image_url[]`。
- [ ] 固定 4 秒/720P 的 UI 与后端校验一致。
- [ ] 不出现在“参考视频”模型列表。

**验证**

- [ ] 官方示例 Payload 测试与一次手动冒烟测试通过。

**依赖**：Task 11

## Final Checkpoint

- [ ] 全部自动化测试不调用真实付费模型。
- [ ] 真实供应商冒烟测试有显式人工开关。
- [ ] 签名 URL 和密钥不出现在日志、SSE 或任务历史中。
- [ ] 供应商输出在过期前完成转存。
- [ ] 用户确认后再开始 Phase 1 实现。
