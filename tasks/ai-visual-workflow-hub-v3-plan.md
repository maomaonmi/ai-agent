# 视频流工作台主页与画布持久化计划

## 目标

将现有独立画布编辑器升级为“视频流工作台”主页，并修复生成结果保存后刷新丢失的问题。

## 实施顺序

1. 将成功运行节点的 output artifacts 写入可保存的节点配置，并在 hydrate 时恢复节点预览。
2. 新增 `/visual-workflow` 工作台主页：新建画布、历史画布、主题同步和错误/空状态。
3. 将编辑器迁移到 `/visual-workflow/canvas/{workflowId}`，支持加载指定画布。
4. 让侧边栏和编辑器左上角品牌入口统一回到工作台主页。
5. 运行契约测试、TypeScript、定向 ESLint 和本地路由检查。

## 验收标准

- 运行成功后点击保存，刷新编辑器仍能看到节点输出预览。
- `/visual-workflow` 只展示工作台主页，历史画布卡片可进入对应编辑器。
- “新建画布”创建后进入独立的画布路径。
- 主题跟随设置，不新增积分或改变现有主题色。
- 旧的侧边栏入口不再直接打开聊天上方的编辑器。

## 风险

供应商返回的临时 URL 仍可能有有效期；本次先持久化 artifact 引用，后续如需永久保留需增加 OSS 归档复制。
