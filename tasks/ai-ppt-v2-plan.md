# AI PPT V2 计划

## 目标

把 V1 的可交互工作台升级为“可恢复、可并发、可观测”的服务端工作流：每个新入口创建独立演示文稿，编辑操作通过 revision 原子提交，AI 运行通过事件账本回放；素材收集、生成与导出均由后端契约约束。

## 交付切片

1. Presentation API：创建/读取演示文稿，批量提交 `PresentationOperation`，使用 `baseRevision` 做乐观并发控制，并返回稳定错误码。
2. 工作台持久化：前端进入新会话时创建空白文稿，刷新后从服务端恢复；编辑器操作异步保存并处理冲突。
3. Agent Loop：run 状态机、可重放事件、SSE 订阅与取消；搜索轮次每次最多 20 条并记录 provider/查询/来源。
4. 素材安全边界：网页图片 SSRF 防护、来源与授权记录，网页图片至少 3 张、AI 生成图片至少 3 张后才能进入排版阶段。
5. 交付验证：浏览器回归、LibreOffice 导出校验、接口/安全测试与 V2 文档。

## 约束

- 私有模板仅用于提取主题、配色、版式；原始 PPT 与预览资产始终按 owner 隔离。
- 单次搜索最多 20 条；provider 适配器不在前端暴露密钥。
- 所有写操作需带幂等 operationId 或 runId；SSE 支持 `Last-Event-ID` 回放。
- 保持 V1 的视觉语言：左侧可伸缩 AI 对话，右侧逐组件搭建编辑器。
