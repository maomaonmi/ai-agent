# AI 视觉工作流实施清单

> 状态：Phase 1/2 已开始执行。后端契约、SQLite 修订仓库与 REST 基础已落地；前端画布骨架正在增量实现。每个任务必须独立可验证，不允许自动化测试调用真实付费模型。

## Phase 1：契约与持久化基础

### Task 1：定义工作流文档与节点注册表（契约骨架已完成）

**描述：** 建立 `WorkflowDocumentV1`、判别联合节点类型、端口类型、节点定义版本和统一错误结构，前后端使用相同稳定字符串。

**验收标准：**

- [ ] 图文档不包含运行状态、临时 URL 或供应商 Task ID。
- [ ] 首期所有节点的输入/输出端口、config schema 和缓存策略可查询。
- [ ] 未知 kind/version 和非法 config 返回结构化错误。

**验证：**

- [x] Pydantic 边界测试通过。
- [x] TypeScript 类型检查通过。

> 说明：节点 configSchema 的逐字段约束将在执行器/适配器阶段补齐；当前先保证版本化节点目录和结构化未知 kind/version 错误。

**依赖：** 无  
**预计范围：** M（3–5 个文件）

### Task 2：建立工作流数据库与修订仓库（基础仓储已完成）

**描述：** 创建 workflow、revision、run、node_run、artifact、cache、event 表和可重复迁移。

**验收标准：**

- [ ] Revision 不可变，保存新版本使用 `baseRevision` 乐观锁。
- [ ] 同一个 `clientRequestId` 不会创建两个 Run。
- [ ] 迁移不修改现有图片/视频任务表语义。

**验证：**

- [x] Repository CRUD、版本冲突测试通过。
- [x] 旧数据库使用 `CREATE TABLE IF NOT EXISTS` 初始化，不改动现有视频/图片任务表。

> 说明：Run/NodeRun 的 `clientRequestId` 幂等约束将在执行 API 落地时启用；当前表结构已预留唯一约束。

**依赖：** Task 1  
**预计范围：** M（3–5 个文件）

### Checkpoint A：后端契约

- [x] 节点目录 API 返回稳定 schema。
- [x] 工作流可创建、保存、读取、分页和软删除。
- [x] 所有错误使用统一 `{error:{code,message,details}}`。

## Phase 2：可编辑无限画布

### Task 3：建立视觉工作流入口与画布骨架（第一版已完成）

**描述：** 安装 `@xyflow/react`、Zustand，新增侧边栏“视觉工作流”入口和独立全屏工作台。

**验收标准：**

- [x] 支持缩放、平移、MiniMap、Controls 和主题同步。
- [x] 左侧节点面板、中央画布、右侧检查面板布局成立；运行面板保留为后续执行阶段。
- [x] 不修改现有主题色，不添加积分按钮。

**验证：**

- [ ] 320/768/1024/1440px 响应式检查通过。
- [ ] 键盘 Tab、删除、缩放和焦点可见性检查通过。

**依赖：** Task 1  
**预计范围：** M（3–5 个文件）

### Task 4：实现节点命令与 Undo/Redo（第一版已完成）

**描述：** 用 Zustand 管理文档状态，节点增删移动、边操作和参数更新都通过可撤销命令。

**验收标准：**

- [x] 编辑命令最多保留 100 步 Undo/Redo。
- [ ] viewport、selection、运行进度不进入撤销历史。
- [ ] 节点组件不订阅完整 nodes/edges 数组。

**验证：**

- [ ] Store 单元测试覆盖添加、删除、移动、参数更新和撤销重做。
- [ ] 100 个节点拖动画布无明显输入延迟。

**依赖：** Task 3  
**预计范围：** M（3–5 个文件）

### Task 5：实现强类型连线与 DAG 校验（第一版已完成）

**描述：** 前端用 `isValidConnection` 即时校验端口类型、连接数和环；后端提供权威 validate API。

**验收标准：**

- [ ] 非法类型、自连、重复边、超连接数和成环均不能保存执行。
- [ ] 无效连接显示原因，不能只通过颜色表达。
- [ ] 前后端对相同图得到相同校验结果。

**验证：**

- [x] 类型矩阵和环检测逻辑已加入前端连接守卫与后端校验器。
- [x] API 伪造非法图测试返回 422。

**依赖：** Task 1、Task 3  
**预计范围：** M（3–5 个文件）

### Checkpoint B：画布编辑

- [ ] 新建工作流、拖入节点、合法连线、保存、刷新恢复闭环通过。
- [ ] 两个标签页并发保存时返回 409，不静默覆盖。
- [ ] 明暗主题与现有设置同步。

## Phase 3：无付费 DAG 执行内核

### Task 6：实现 DAG 编译器和拓扑批次

**描述：** 将固定 Revision 编译为 predecessor map，用 `TopologicalSorter` 产生可并行批次。

**验收标准：**

- [ ] 同层无依赖节点进入同一 ready 批次。
- [ ] 一个分支失败只跳过其后代，其他分支继续。
- [ ] 循环图在执行前失败，不创建付费节点任务。

**验证：**

- [ ] 链式、扇出、汇聚、独立分支、环路测试通过。
- [ ] 执行顺序测试不依赖字典偶然顺序。

**依赖：** Task 2、Task 5  
**预计范围：** M（3–5 个文件）

### Task 7：实现 Run/NodeRun 状态机与恢复

**描述：** 建立持久化执行器、状态转换、取消和应用重启恢复。

**验收标准：**

- [ ] Run 与 NodeRun 只允许合法状态转换。
- [ ] 重启后 RUNNING/READY 节点可对账或恢复，不重复提交。
- [ ] 取消后不再派发新节点。

**验证：**

- [ ] 状态机、重复调度、取消和重启恢复测试通过。

**依赖：** Task 6  
**预计范围：** M（3–5 个文件）

### Task 8：实现工作流 SSE 和轮询兜底

**描述：** 持久化事件序列，通过 SSE 推送运行/节点事件，并支持断线重放。

**验收标准：**

- [ ] `Last-Event-ID` 后只补发缺失事件。
- [ ] SSE 断开后前端每 3 秒读取 Run 快照。
- [ ] 事件不暴露签名 URL、密钥或供应商原始敏感响应。

**验证：**

- [ ] 事件顺序、断线、重连、heartbeat 测试通过。

**依赖：** Task 7  
**预计范围：** M（3–5 个文件）

### Task 9：实现内容哈希缓存

**描述：** 基于节点定义、适配器版本、标准化参数和上游 artifact hash 建立增量缓存。

**验收标准：**

- [ ] 移动节点、缩放画布或重命名不改变 cache key。
- [ ] 参数、上游内容或 adapterVersion 改变会失效缓存。
- [ ] 缓存命中前验证 artifact 仍存在。

**验证：**

- [ ] 缓存黄金键、命中、失效和过期测试通过。

**依赖：** Task 2、Task 6  
**预计范围：** S（1–2 个文件）

### Checkpoint C：无付费执行

- [ ] prompt/template/preview/gallery 工作流可完整执行。
- [ ] 分叉与汇聚结果正确，节点状态实时展示。
- [ ] 重跑相同图全部命中缓存。

## Phase 4：图片节点纵向闭环

### Task 10：接入图片输入和视觉理解节点

**描述：** 复用现有图片上传资产与 Qwen/GLM 视觉识别能力，输出 prompt artifact。

**验收标准：**

- [ ] 图片输入只传播 artifactId，不传播 Base64 到图文档。
- [ ] 视觉模型可选择，错误保留节点级结构化信息。
- [ ] 相同图片与参数可命中缓存。

**验证：**

- [ ] 假模型适配器契约测试通过。
- [ ] 自动化测试不调用真实付费模型。

**依赖：** Task 9  
**预计范围：** M（3–5 个文件）

### Task 11：接入图片生成、编辑和对比节点

**描述：** 复用现有图片模型矩阵，实现提示词/参考图输入和多分支结果比较。

**验收标准：**

- [ ] 同一图片/提示词可分叉到三个不同模型并行运行。
- [ ] 每个节点保留独立模型参数、产物和错误。
- [ ] Gallery 可按模型、耗时、缓存命中展示结果。

**验证：**

- [ ] 三分支假供应商端到端测试通过。
- [ ] 浏览器检查节点状态、预览和对比布局。

**依赖：** Task 10  
**预计范围：** M（3–5 个文件）

### Checkpoint D：图片模型

- [ ] “人物图 → 三模型分叉 → 对比结果”完整闭环通过。
- [ ] 重跑未修改节点不产生新供应商任务。
- [ ] 单分支失败不影响其他模型结果。

**验收标准：**

- [ ] 模型能力自动决定端口和参数可用性。
- [ ] 不复制供应商轮询/SSE/资产下载逻辑。
- [ ] 视频成功后输出稳定 video artifactId。

**验证：**

- [ ] 三种模式假供应商执行测试通过。

**依赖：** Task 9  
**预计范围：** M（3–5 个文件）

**验收标准：**

- [ ] 只有 READY 且未过期资产可执行。
- [ ] 最多 3 个参考视频和模型能力限制一致。
- [ ] 单工作区视频节点默认串行，图片分支仍可并发。

**验证：**

- [ ] 资产过期、预处理中、并发和恢复测试通过。

**依赖：** Task 12  
**预计范围：** M（3–5 个文件）

### Checkpoint E：多模态流水线

- [ ] “提示词 + 参考图 → 图片编辑 → 图生视频 → 预览”闭环通过。
- [ ] “参考视频 + 提示词 → R2V → 预览”闭环通过。

## Phase 6：增量运行与发布准备

### Task 14：实现从节点运行、失败重试和子图计算

**描述：** 支持只运行目标节点所需祖先及受影响后代，成功节点通过缓存复用。

**验收标准：**

- [ ] 从节点运行不执行无关分支。
- [ ] 重试创建新 attempt，不覆盖历史 NodeRun。
- [ ] 修改节点后只使其自身和后代缓存失效。

**验证：**

- [ ] 子图闭包、attempt 和局部失效测试通过。

**依赖：** Task 13  
**预计范围：** M（3–5 个文件）

### Task 15：完成成本、安全与可观测性护栏

**描述：** 加入运行前摘要、并发限制、SSRF 防护、审计日志和基础指标。

**验收标准：**

- [ ] 运行前展示预计会调用的付费节点数量，不虚构金额。
- [ ] 任意 URL、自定义代码和跨工作区资产引用被拒绝。
- [ ] 可查询节点耗时、供应商、缓存命中和失败类别。

**验证：**

- [ ] 安全边界、并发、日志脱敏和指标测试通过。

**依赖：** Task 14  
**预计范围：** M（3–5 个文件）

- [ ] 320/768/1024/1440px 与明暗主题通过。
