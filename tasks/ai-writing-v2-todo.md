# AI 写作 V2 任务清单

> 前置：等待 `tasks/ai-writing-v2-plan.md` 产品确认后实施。

## Phase 0：契约与迁移

- [ ] 定义 `WritingDocumentState`、章节、引用、版本和文档事件类型。
- [ ] 将 V1 单篇正文转换为 V2 单章节文档。
- [ ] 增加 SSE 事件版本和事件回放测试。
- [ ] 增加旧会话兼容测试。

## Phase 1：双栏工作台

- [ ] 拆分顶栏、左栏协作区、右栏文档区、分隔线和移动端切换器。
- [ ] 实现大纲/正文/排版三视图和明确的文档生成样式。
- [ ] 实现空状态、生成中、失败、重试、保存状态。
- [ ] 验证正文只在右栏生成。

## Phase 2：论文 Deep Research

- [ ] 研究计划和阶段进度。
- [ ] 多轮检索与来源列表。
- [ ] 证据卡片和来源回放。
- [ ] 分章节写作、暂停、取消、重试和降级状态。

## Phase 3：引用核验

- [ ] 建立正文句子与来源证据的引用锚点。
- [ ] 实现已核验/部分支持/未支持/待确认状态。
- [ ] 实现证据抽屉和未核验警示。
- [ ] 生成参考文献区。

## Phase 4：Character 与长文编排

- [ ] 角色卡和角色接力状态。
- [ ] 章节队列、目标字数和 checkpoint。
- [ ] 支持 3000/8000/10000/20000/30000 字规划档位。
- [ ] 支持单章重试、重排和继续生成。

## Phase 5：意图与版本

- [ ] 意图识别建议层和手动覆盖。
- [ ] 全文/章节版本树。
- [ ] 版本 diff：新增、删除、修改、引用变化。
- [ ] 预览式全文改写、确认替换和恢复。

## Phase 6：质量验收

- [ ] 大文档分段/虚拟化渲染。
- [ ] 网络中断、刷新恢复、暂停重试测试。
- [ ] 键盘、屏幕阅读器、reduced motion 检查。
- [ ] 1440/1024/768/320 视觉验收并更新 `design-qa.md`。
- [ ] TypeScript、限定 ESLint、Python 测试和生产构建。
