# AI 生图模块实施任务清单

> 关联计划：`tasks/ai-image-studio-plan.md`

## Task 1：冻结统一契约与状态机

**描述：** 定义模型能力、导演输出、生成请求、批次、任务、资产、错误和状态转换。

**验收标准：**

- [ ] 自动与手动模型模式可被类型系统表达；
- [ ] 状态机覆盖成功、失败、取消、中断和下载阶段；
- [ ] API 示例与前后端类型一致。

**验证：** 合约单元测试；非法状态转换测试。  
**依赖：** 无。  
**规模：** M。

## Task 2：建立模型能力注册表

**描述：** 将目标模型的供应商 ID、任务类型、尺寸、输出数和可选参数集中到后端。

**验收标准：**

- [ ] 七个目标模型均有能力声明；
- [ ] 未配置或禁用模型不会参与路由；
- [ ] 前端可从 API 获取能力，不维护重复常量。

**验证：** 注册表快照测试；边界尺寸与张数测试。  
**依赖：** Task 1。  
**规模：** S。

## Task 3：完成数据库迁移与 Repository

**描述：** 新增批次、资产、事件表及查询、软删除、幂等和状态更新能力。

**验收标准：**

- [ ] 重启后批次、参数与资产记录仍存在；
- [ ] 相同幂等键只能创建一个任务；
- [ ] 分页、搜索、筛选和软删除可用。

**验证：** SQLite 集成测试；迁移升级测试。  
**依赖：** Task 1。  
**规模：** M。

## Checkpoint A：基础契约

- [ ] Task 1—3 测试全部通过；
- [ ] 数据库可从空库自动初始化；
- [ ] 计划中的 API JSON 能由真实类型序列化。

## Task 4：实现安全的本地图片存储

**描述：** 下载供应商图片、校验格式与大小、原子落盘并生成缩略图。

**验收标准：**

- [ ] 成功作品不依赖供应商临时 URL；
- [ ] 非 HTTPS、超限响应和伪造 MIME 被拒绝；
- [ ] 原图和缩略图可通过受控 API 读取。

**验证：** 本地 HTTP fixture；失败与中断下载测试。  
**依赖：** Task 3。  
**规模：** M。

## Task 5：接入千问 Provider

**描述：** 为 Qwen Image、Wan 与 Z-Image 实现统一适配器和错误映射。

**验收标准：**

- [ ] 每个模型只收到自身支持的参数；
- [ ] 多图、顺序模式和异步状态正确归一；
- [ ] 鉴权、限流、余额、内容安全和超时错误可区分。

**验证：** mock 合约测试；显式开关的真实 API 冒烟测试。  
**依赖：** Task 1、2、4。  
**规模：** M。

## Task 6：接入智谱 Provider

**描述：** 实现 GLM-Image 与 CogView-4 的请求、尺寸适配、内容过滤和资产下载。

**验收标准：**

- [ ] `cogview-4` 别名映射到实际可用模型 ID；
- [ ] GLM 与 CogView 使用各自尺寸和质量约束；
- [ ] `content_filter` 被记录并安全展示。

**验证：** mock 合约测试；显式开关的真实 API 冒烟测试。  
**依赖：** Task 1、2、4。  
**规模：** M。

## Checkpoint B：供应商闭环

- [ ] 千问至少一个模型完成“请求 → 下载 → 持久化”；
- [ ] 智谱至少一个模型完成“请求 → 下载 → 持久化”；
- [ ] 远端 URL 失效后本地作品仍可读取。

## Task 7：实现视觉导演

**描述：** 将用户需求转换为结构化意图、双语增强提示词、负向提示词和推荐信号。

**验收标准：**

- [ ] 原始需求与增强结果分别保存；
- [ ] 必须呈现的中文文本可被提取；
- [ ] 输出不合法时有确定性回退规则。

**验证：** 固定提示词评测集；结构化输出容错测试。  
**依赖：** Task 1、2。  
**规模：** M。

## Task 8：实现路由、回退与任务编排

**描述：** 完成能力过滤、加权评分、手动锁模、参数适配、任务执行和一次性回退。

**验收标准：**

- [ ] 路由给出可展示的推荐原因；
- [ ] 手动模型不会被导演改写；
- [ ] 只对明确可重试错误回退且最多一次。

**验证：** 路由矩阵测试；幂等与重复扣费防护测试。  
**依赖：** Task 2、3、5、6、7。  
**规模：** M。

## Task 9：提供 Image Studio API

**描述：** 装配模型、导演、任务、批次、资产、取消、重试与健康检查端点。

**验收标准：**

- [ ] 创建任务返回 202 和持久化 task_id；
- [ ] API 不泄露密钥和文件系统真实路径；
- [ ] 错误响应包含 retryable 与用户建议。

**验证：** FastAPI 合约测试；OpenAPI schema 检查。  
**依赖：** Task 3、4、8。  
**规模：** M。

## Checkpoint C：后端端到端

- [ ] 七个模型都有可验证的能力声明；
- [ ] 自动和手动模型流程均通过；
- [ ] 失败、取消、回退和重试状态可追踪。

## Task 10：接入两个统一入口

**描述：** 在展开/折叠侧边栏与输入框“更多”菜单接入同一 Image Studio 视图。

**验收标准：**

- [ ] 两个入口打开同一个工作台；
- [ ] 输入框已有文字时只带入草稿，不自动生成；
- [ ] 返回聊天不会丢失已提交的后台任务。

**验证：** 组件测试；手动导航检查。  
**依赖：** Task 1。  
**规模：** S。

## Task 11：实现创作器与导演建议

**描述：** 构建空状态、自然语言输入、自动/手动模式、动态参数和导演建议卡。

**验收标准：**

- [ ] 基础生成只需输入一句话；
- [ ] 参数会随模型能力动态变化；
- [ ] 增强提示词可查看、编辑、恢复或关闭。

**验证：** 前端组件测试；键盘与移动端检查。  
**依赖：** Task 2、7、9、10。  
**规模：** M。

## Task 12：实现生成进度与恢复

**描述：** 轮询任务状态，展示真实阶段，并处理离页、取消、失败和重启恢复。

**验收标准：**

- [ ] 不展示伪百分比；
- [ ] 刷新后可恢复任务；
- [ ] 每类失败都提供正确下一步。

**验证：** 状态机 UI 测试；刷新和服务重启手动测试。  
**依赖：** Task 8、9、11。  
**规模：** M。

## Task 13：实现画廊、Lightbox 与作品库

**描述：** 实现结果网格、全屏查看、下载、做同款、重试、搜索筛选与软删除。

**验收标准：**

- [ ] 作品按批次浏览且元数据完整；
- [ ] Lightbox 支持键盘切换和关闭；
- [ ] 重启后可搜索并复用历史作品。

**验证：** 组件与 API 集成测试；无障碍检查。  
**依赖：** Task 3、4、9、12。  
**规模：** M。

## Checkpoint D：完整用户旅程

- [ ] “进入 → 描述 → 推荐 → 生成 → 查看 → 下载 → 做同款”端到端通过；
- [ ] 桌面端和移动端核心流程可完成；
- [ ] 未配置 API Key 时提供设置入口且页面不崩溃。

## Task 14：安全、可靠性与发布验收

**描述：** 完成限流、日志脱敏、容量控制、垃圾回收、真实冒烟、构建和回归。

**验收标准：**

- [ ] API Key、Authorization 和本地真实路径不出现在响应与日志；
- [ ] 重复提交、恶意 URL、大文件和中断写入均有防护；
- [ ] 前后端构建、自动化测试和供应商冒烟通过。

**验证：** 全量测试；安全用例；生产式构建。  
**依赖：** Task 1—13。  
**规模：** M。

## 最终评审

- [ ] 产品负责人确认模型自动推荐与手动覆盖体验；
- [ ] 开发确认官方模型 ID、参数、计费和并发限制仍有效；
- [ ] Definition of Done 全部满足；
- [ ] 首版范围外需求进入后续 Backlog，不阻塞发布。
