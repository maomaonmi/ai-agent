# AI 写作论文场景任务清单

> 依据：`tasks/ai-writing-thesis-outline-plan.md`
> 状态：计划已确认，可进入实施

## Phase A：状态契约与场景门控

### Task 1：定义论文文档契约

**验收标准：**

- [x] 定义论文大纲、大章节、子章节、参考资料、字数预算和版本类型。
- [x] 类型与普通写作文档兼容，但论文状态不依赖 React 组件。
- [ ] 为旧单篇正文提供安全迁移路径。

**验证：** TypeScript 类型检查和类型级回归。

### Task 2：实现论文专属标签和提交路由

**验收标准：**

- [x] 只有论文场景显示“大纲 / 正文 / 排版”。
- [x] 其他场景只显示“正文 / 排版”。
- [x] 论文第一次提交只请求大纲，其他场景保持正文生成。

**验证：** 八种场景浏览器检查和路由测试。

### Checkpoint A

- [ ] 论文与普通写作链路互不污染。
- [ ] 现有历史写作会话可打开。

## Phase B：真实流式大纲

### Task 3：实现大纲提示词与服务端事件

**验收标准：**

- [x] 输入题目、论文类型、学段和目标字数后生成结构化大纲。
- [x] 服务端以独立合法 JSON 的 SSE 事件返回标题、章节和子章节。
- [x] 异常时发送明确失败事件且不返回半个无效 JSON。

**验证：** 提示词结构测试、SSE 契约测试、不同题目输出差异测试。

### Task 4：实现论文大纲 reducer 和流式 UI

**验收标准：**

- [x] 事件可幂等重放，不重复增加章节。
- [x] 大纲节点随服务端事件逐步呈现。
- [x] 刷新后恢复已完成节点和生成状态。

**验证：** reducer 单元测试和浏览器限速测试。

### Task 5：实现期望字数和预算

**验收标准：**

- [x] 支持不限、3000、5000、8000、10000、15000、20000、30000。
- [x] 不同档位影响章节数、层级和章节预算。
- [ ] 页面显示目标字数与预算超限提示。

**验证：** 字数映射和预算守恒测试。

### Checkpoint B

- [ ] 论文真实大纲可端到端流式生成。
- [ ] 不再渲染固定章节数组。

## Phase C：章节操作与版本

### Task 6：实现当前大章节长度设置

**验收标准：**

- [x] 菜单含简短、适中、较长和删除大章节。
- [x] 长度只影响当前大章节及其子章节预算。
- [ ] 已生成正文时只标记待重写，不自动覆盖。

**验证：** 长度权重测试和交互测试。

### Task 7：实现添加子章节表单

**验收标准：**

- [x] 点击“＋”展开标题和内容主题两个输入框。
- [x] 两个输入框各自有独立清除按钮。
- [ ] 添加后重新编号并更新当前大章节预算。

**验证：** 清除、取消、快捷键、添加和重新编号测试。

### Task 8：实现候选大纲版本

**验收标准：**

- [ ] “换一换”不覆盖活动大纲。
- [ ] 新版完成后可采用或保留原版。
- [ ] 采用新版后重新搜索，旧版本和旧资料仍可恢复。

**验证：** 版本切换和恢复测试。

### Checkpoint C

- [ ] 用户可以完整编辑大纲且不丢版本。

## Phase D：联网搜索与参考资料

### Task 9：建立千问论文搜索适配器

**验收标准：**

- [x] 使用千问原生来源返回能力，不依赖普通聊天占位引用。
- [x] 支持 Deep Research 原生阶段、来源返回和 WebResearch 阶段提前来源。
- [x] 错误、限流和模型不支持时返回可恢复状态。

**验证：** Mock API、错误映射和配置测试。

### Task 10：实现按大章节检索和网页抓取

**验收标准：**

- [x] 每章独立构造查询并绑定 chapter ID。
- [x] URL 去重、过滤和抓取证据片段。
- [x] 每章目标 4–6 条、最多 6 条，不足时展示真实结果。

**验证：** 去重、排序、数量上限和不足场景测试。

### Task 11：实现参考资料 UI

**验收标准：**

- [x] 入口位于段落设置和“＋”左侧。
- [x] 搜索中显示进度，完成后显示实际数量。
- [x] 展开后显示标题、域名、摘要、URL 和状态。

**验证：** 截图对比、键盘和空/错/加载状态检查。

### Checkpoint D

- [x] 每个大章节都能查看真实、可点击、可追溯的参考资料。

## Phase E：基于大纲生成正文

### Task 12：实现底部大纲操作条

**验收标准：**

- [x] 大纲底部固定显示“换一换”和“基于大纲生成正文”。
- [x] 按生成、搜索、失败状态正确启用或禁用。
- [x] 正文生成中按钮变为暂停入口。

**验证：** 状态矩阵组件测试。

### Task 13：实现章节正文流式事件

**验收标准：**

- [x] 正文按章节和子章节生成。
- [x] Token 实时写入对应章节，不等待全文结束。
- [x] 引用事件绑定真实 reference ID。

**验证：** SSE 契约、流式顺序和引用映射测试。

### Task 14：实现暂停、恢复与 checkpoint

**验收标准：**

- [x] 用户可暂停和继续生成。
- [x] 刷新或失败后从最后完成章节继续。
- [x] 重试不会重复写入已完成内容。

**验证：** 中断、重连、重复事件和恢复测试。

### Checkpoint E

- [x] 论文从真实大纲到流式正文完整可用。

**验收标准：**

- [ ] 1440/1024/768/320 无关键布局溢出。
- [x] 大纲和正文流式更新无明显卡顿。
- [x] TypeScript、限定 ESLint、相关 Python/前端测试通过。
- [ ] 与参考截图比较后无 P0/P1/P2 问题。
